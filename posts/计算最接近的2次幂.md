**所有的方法都围绕一个核心**
> 找到二进制中最高位的1在哪里

任意正整数都可以写成
$$ x = 2^k + r, 0 <= r < 2^k$$

例如
```text
x = 20
x = 0b10100
x = 00000000 00000000 00000000 00010100
    |<--------27个前导零--------->|
```

最高位的1在第4位(0索引起始), $k = 4$
所以
$$ceil\_power\_2(20) = 1 << 4 = 16$$
$$floor\_power\_2(20) = 1 << (4 + 1) = 1 << 5 = 32$$

### clz (count leading zero)

找到前导零

例如， clz =4，

那么

## 最大的小于等于数字x的2次幂

\begin{align}
ceil\_power\_2(x)&= 1 << (31 - \_\_clz(x))
\end{align}

> clz(x)





得到前导零的长度为27，因为在长度为32的比特位中，索引是0-31，要得到最高位为1的索引，则是
$$31 - clz(x) = 31 - 27 = 4$$

\begin{align}
ceil\_power\_2(x)&= 1 << (31 - \_\_clz(x))\\
&= 1 << (31 - 27)\\
&= 1 << 4\\
&= 16
\end{align}


## 最小的大于等于数字x的2次幂

\begin{align}
floor\_power\_2(x)&= 1 << (32 - \_\_clz(x - 1))
\end{align}

$$floor\_power\_2(x)= 1 << (32 - \_\_clz(x - 1))$$

### 为什么会有x - 1？

因为这里的情况是要找到**大于等于**的$2^k$，要支持到等于$2^k$这种情况，转换问题为寻找一个$2^k > x-1$




### 为什么求最小的2次幂是32 - clz(x - 1)，求最大的2次幂又是31 - clz(x)
> 为什么有的时候用31，有的时候又用32

$$31 - clz(x)$$
得到的是x的二进制中最高位为1的索引，但是我们要找的是$2^k >= x$，所以公式最后要 + 1

\begin{align}
1 &<< (31 - clz(x - 1) + 1) &<< (32 - clz(x - 1))
\end{align}
